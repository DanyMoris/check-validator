# Пробные файлы для заказчика

Наивные подделки (Word, «печать в PDF», самодельная квитанция) заказчик уже
видел — они слишком заметны. Здесь лежат **похожие на живые** чеки ВТБ:
шаблон банка не пересобирался, в файле подменена только сумма.

Текст для отправки заказчику — в `сообщение_заказчику.txt`.

| Файл | На экране | Вердикт бота |
|------|-----------|----------------|
| `lookalike_vtb_410_na_589.pdf` | 589 ₽ | **НЕ ПОДТВЕРЖДЁН** |
| `lookalike_vtb_500_na_499.pdf` | 499 ₽ | **НЕ ПОДТВЕРЖДЁН** |
| `lookalike_vtb_900_na_999.pdf` | 999 ₽ | **НЕ ПОДТВЕРЖДЁН** |

В Telegram: скрепка → **Файл**. Настоящий PDF из приложения банка тоже не
должен стать «ПОДДЕЛКА».

Пересобирать: `.venv\Scripts\python.exe tools\forge_lookalike.py`

PDF в git не входят (персональные данные шаблона). Не пересылайте папку
третьим лицам.
