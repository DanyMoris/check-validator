# Пробные файлы для заказчика

Сюда положены **поддельные** PDF, чтобы проверить бота без живого мошенника.

Два первых файла сделаны из настоящего чека ВТБ: на странице всё ещё видны
реквизиты тестового корпуса — **не пересылайте папку третьим лицам**.
Третий файл собран с нуля, без чужих данных.

В Telegram: скрепка → **Файл** (не фото). Если бот спросит банк и тип —
для 01 и 02 можно «Определить самим»; для 03 сравните оба варианта.

| Файл | Что сделано | Вердикт |
|------|-------------|--------|
| `01_poddelka_office.pdf` | Чек пересохранён «как из Word / Print to PDF» | **ПОДДЕЛКА** |
| `02_poddelka_dovpiska.pdf` | В конец настоящего PDF дописана лишняя ревизия | **ПОДДЕЛКА** |
| `03_samodelnyi.pdf` | Самодельная «квитанция», банка в эталонах нет | **НЕ ПОДТВЕРЖДЁН**; если выбрать «ВТБ / Чек» — **ПОДДЕЛКА** |

Настоящий PDF из банковского приложения **не** должен стать «ПОДДЕЛКА».
Чтобы получить **ПОДТВЕРЖДЁН** на обычном чеке, внесите поступление вручную,
затем пришлите тот же файл:

```
/income <сумма> <дата> <время>
```

Например: `/income 410 02.09.2026 13:02`. Журнал на этом этапе только ручной:
`/income` или `/statement` с **выпиской по счёту** (не по карте).

Пересохранение «как есть» той же программой, что у банка, мы намеренно не
ловим. Такие случаи закрывает только сверка с журналом.
