# Check Validator

Telegram-бот, который проверяет PDF чеков, квитанций и справок российских банков
(ВТБ, Сбер, Альфа, Т-Банк). Работает **на вашем компьютере**, без платных внешних
служб: телефон только пишет боту, программа на ПК забирает файлы и отвечает.

Скриншоты не принимаются. Вердикт бывает трёх видов:

- **ПОДДЕЛКА** — файл не похож на банковский или его сохранили не той программой
  (Word, Acrobat, «печать в PDF»);
- **ПОДЛИННЫЙ** — режим без выписок: страница совпала с шаблоном банка (это не
  доказательство платежа);
- **НЕ ПОДТВЕРЖДЁН** — режим с выписками: следов подделки нет, но поступления
  в журнале нет;
- **ПОДТВЕРЖДЁН** — подпись банка (справки ВТБ) или совпадение с журналом
  (±2 суток).

## Запуск на компьютере

Компьютер должен быть включён и иметь интернет. Это не сайт и не приложение в
телефоне: пока программа на ПК не запущена, бот в Telegram молчит.

### Что нужно

- Windows 10 или 11
- [Python 3.11 или новее](https://www.python.org/downloads/) — при установке
  отметьте **Add python.exe to PATH**
- Аккаунт Telegram
- Токен бота от [@BotFather](https://t.me/BotFather)

### 1. Скачать проект

```powershell
git clone https://github.com/DanyMoris/check-validator.git
cd check-validator
```

Если Git не установлен, скачайте ZIP с GitHub (зелёная кнопка **Code → Download
ZIP**) и распакуйте в удобную папку, например `C:\check-validator`. Дальше все
команды выполняются **в корне этой папки**.

Эталоны банков уже лежат в `profiles/profiles.yaml`. Команду
`tools\build_profiles.py` при обычной установке **не запускайте**: она
пересобирает эталоны из локальных образцов и без них затрёт реестр.

### 2. Виртуальное окружение и библиотеки

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

Если Windows ругается на политику скриптов при активации `.venv`:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Активация не обязательна: дальше везде можно вызывать
`.venv\Scripts\python.exe` напрямую.

### 3. Токен бота

1. В Telegram найдите [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя и username (username должен оканчиваться на
   `bot`).
3. BotFather пришлёт токен вида `123456:ABC-DEF...`. Никому его не пересылайте.
4. Для личных сообщений больше ничего настраивать не нужно.

### 4. Файл настроек

```powershell
copy .env.example .env
notepad .env
```

Минимум:

```
BOT_TOKEN=вставьте_токен_сюда
ALLOWED_USER_IDS=
```

Пока `ALLOWED_USER_IDS` пуст, бот отвечает всем, кто его найдёт. Это удобно в
первый раз: напишите боту `/id`, он покажет ваш номер. Затем закройте вход:

```
ALLOWED_USER_IDS=123456789
```

Несколько человек — через запятую. После изменения `.env` бота нужно
перезапустить (остановить задачу в Планировщике или закрыть окно и запустить
снова).

Не копируйте чужой `.env` и чужой `data/bot.db`: у каждого компьютера свой
токен и свой журнал.

### 5. Первый запуск (в окне)

Чтобы убедиться, что всё работает:

```powershell
.\.venv\Scripts\python.exe -m checkvalidator.cli bot
```

Окно должно оставаться открытым. В логе появится
`Бот запущен, ожидание сообщений…`. Остановка — `Ctrl+C`.

Дальше в Telegram: **Start** или `/start`, затем скрепка → **Файл** → PDF из
банковского приложения (не фото и не скриншот). Если не уверены в типе
документа — «Определить самим».

Когда ручной запуск проверен, можно повесить бота на автозапуск — см. ниже.

## Автозапуск через Планировщик заданий Windows

Бот должен подниматься после включения компьютера и входа в учётную запись,
без ручного открытия окна. Для этого нужен Планировщик заданий.

Скрипт `scripts\run_bot.cmd` сам переходит в папку проекта, запускает бота и
пишет лог в `data\bot.log`.

### Через окно Планировщика

1. Клавиши **Win+R**, введите `taskschd.msc`, Enter.
2. Справа: **Создать задачу…** (не «Создать простую задачу» — там меньше
   настроек).
3. Вкладка **Общие**:
   - Имя: `Check Validator Bot`
   - Выберите **Выполнять только для вошедшего пользователя**
   - Отметьте **Скрытая**, если не нужно всплывающее окно консоли
   - Внизу в «Настроить для» оставьте Windows 10 (или Windows 11)
4. Вкладка **Триггеры** → **Создать…**:
   - Начать задачу: **При входе в систему**
   - Пользователь — та учётная запись, под которой ставили Python
   - Отметьте **Отложить задачу на** `1 минута` (чтобы успел подняться Wi‑Fi)
   - ОК
5. Вкладка **Действия** → **Создать…**:
   - Действие: **Запуск программы**
   - Программа или сценарий: полный путь к `scripts\run_bot.cmd`
     (например `C:\check-validator\scripts\run_bot.cmd`)
   - Рабочая папка: корень проекта (`C:\check-validator`)
   - Поле «Добавить аргументы» оставьте пустым
   - ОК
6. Вкладка **Условия**:
   - Снимите **Запускать только при питании от электросети** (иначе на
     ноутбуке от батареи бот не стартует)
   - Можно отметить **Запускать только при подключении к следующей сети**
     и выбрать любую сеть — или оставить как есть, если интернет всегда есть
7. Вкладка **Параметры**:
   - Отметьте **При сбое выполнения перезапускать через** `1 мин`, число
     попыток — `3`
   - Если задача уже выполняется: **Не запускать новый экземпляр**
8. ОК. Если Windows спросит пароль учётной записи — введите его.

Проверка: в списке задач найдите `Check Validator Bot` → справа **Выполнить**.
Через полминуты напишите боту `/start`. Если молчит — откройте `data\bot.log`.

Чтобы остановить: в Планировщике **Завершить**. Чтобы не запускать после
перезагрузки — снимите галочку у задачи или удалите её.

### Той же командой в PowerShell

Подставьте свой путь вместо `C:\check-validator`:

```powershell
$root = "C:\check-validator"
$cmd  = Join-Path $root "scripts\run_bot.cmd"
schtasks /Create /TN "CheckValidatorBot" /TR $cmd /SC ONLOGON /DELAY 0001:00 /RL LIMITED /F
```

Потом откройте задачу в Планировщике и снимите «только от электросети», как в
шаге 6 выше: у `schtasks` этой галочки нет.

### Что помнить

- Спящий режим и выключение ПК останавливают бота. Для постоянной работы
  компьютер должен быть включён, пользователь — войти в Windows, интернет —
  работать.
- После правки `.env` завершите задачу и запустите её снова (или перезагрузите
  ПК).
- Не ставьте два экземпляра сразу (окно *и* задача): Telegram отдаст обновления
  только одному процессу, ответы будут «теряться».

## Как пользоваться

1. Найдите бота в Telegram по username, который вы задали BotFather.
2. Нажмите **Start** или отправьте `/start`. Бот спросит, есть ли выписки
   по счёту: **есть** — сверка с журналом; **нет** — только файл
   («ПОДЛИННЫЙ» / «ПОДДЕЛКА»).
3. Выгрузите PDF из банковского приложения (не скриншот экрана).
4. В Telegram: скрепка → **Файл** → выберите PDF. Не отправляйте как фото.
5. Выберите банк, затем тип документа (Чек / Квитанция / Справка).
   Если не уверены — «Определить самим». Указанный тип делает проверку строже.
6. Прочитайте вердикт.

Команды:

| Команда      | Зачем                                       |
|--------------|---------------------------------------------|
| `/start`     | Краткая инструкция                          |
| `/help`      | То же самое                                 |
| `/id`        | Ваш Telegram ID, чтобы внести в список      |
| `/profiles`  | Какие эталоны банков уже собраны            |
| `/income`    | Добавить поступление (сумма и дата или CSV) |
| `/statement` | Загрузить выписку по **счёту** (не по карте)|
| `/coverage`  | Отметить период, за который выписка полная  |
| `/ledger`    | Показать журнал поступлений                 |
| `/cancel`    | Отменить загрузку или ввод поступления      |

### Сверка со счётом

Банковского API у личного счёта нет, поэтому журнал поступлений ведёте вы
(вручную достаточно). Без журнала бот ловит грубые подделки файла, но не может
подтвердить, что деньги реально пришли.

1. `/income 410 02.09.2026 13:02` — одна запись. Она может **подтвердить** чек,
   но не объявить его подделкой: вы могли просто не внести другие платежи.
2. `/statement` — затем **выписка по счёту** (CSV или PDF), не выписка по карте.
   Одна удачная загрузка закрывает сессию. Две и больше операций отмечают
   период покрытия; чек внутри окна без такой суммы остаётся неподтверждённым.
3. `/coverage 01.09.2026 11.09.2026` — сказать то же самое вручную, без файла.

Не загружайте в журнал исходящие чеки отправителя: бот ищет входящие деньги.

Один платёж подтверждает только один файл. Повторная отправка того же PDF
проходит, чужой чек на ту же сумму — нет.

Если этот же файл уже присылали, бот напомнит предыдущий вердикт и дату.

Пробные подделки с **чужими метаданными** (страница как у банка, программа-создатель
чужая) собираются так:

```powershell
.\.venv\Scripts\python.exe tools\populate_fraudulent.py
```

По два PDF на банк в `resources/fraudulent/` (ВТБ чек, Сбер чек, Альфа квитанция,
Т-Банк квитанция). В Telegram: `/start` → **Нет выписок** → скрепка → Файл.
Ожидается **ПОДДЕЛКА**. В git эти PDF не входят — в них те же персональные данные,
что в живых чеках. Подробнее: `resources/README.md`.

Подделки «только сумма» (шаблон банка не ломается) — в `demo/` на машине разработки.

## Данные на диске

- `.env` — токен, не коммитить и никуда не пересылать
- `data/bot.db` — история проверок и журнал поступлений
- `data/inbox/` — копии присланных PDF
- `data/bot.log` — лог, если бот запущен через `scripts\run_bot.cmd`

Это настоящие финансовые документы. Папка `data/` в git не попадает.

## Проверка без Telegram

Тот же детектор из командной строки (для отладки):

```powershell
.\.venv\Scripts\python.exe -m checkvalidator.cli check путь\к\файлу.pdf --expect "VTB/Чек" -v
.\.venv\Scripts\python.exe -m checkvalidator.cli extract путь\к\файлу.pdf
.\.venv\Scripts\python.exe -m checkvalidator.cli income add 410 02.09.2026 13:02
.\.venv\Scripts\python.exe -m checkvalidator.cli income csv выписка.csv
.\.venv\Scripts\python.exe -m checkvalidator.cli income pdf входящая_справка.pdf
.\.venv\Scripts\python.exe -m checkvalidator.cli check путь\к\файлу.pdf --ledger data\bot.db --consume
```

## Для разработки

Образцы настоящих PDF кладутся в `resources/genuine/<БАНК>/<ТИП>/` и в git не
попадают. Пересборка эталонов:

```powershell
.\.venv\Scripts\python.exe tools\build_profiles.py
```

Тесты: `.\.venv\Scripts\python.exe -m pip install -e ".[dev]"` затем
`.\.venv\Scripts\python.exe -m pytest -q`.
